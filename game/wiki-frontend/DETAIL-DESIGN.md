# Ability and move detail pages

## English

The information hierarchy was informed by WikiDex's [Pressure](https://www.wikidex.net/wiki/Presi%C3%B3n) and [Gust](https://www.wikidex.net/wiki/Tornado_(tipo_volador)) pages. The interface uses original wording and local assets; it does not copy their descriptions or images.

Move and ability details use the selected wiki dataset. Species profiles and learnsets include legacy inputs, descriptions use reference sources, and machine compatibility is displayed only with the matching target hash. These pages do not establish untested in-game effects.

## Español

La jerarquía de información se inspiró en las fichas de [Presión](https://www.wikidex.net/wiki/Presi%C3%B3n) y [Tornado](https://www.wikidex.net/wiki/Tornado_(tipo_volador)) de WikiDex. La interfaz utiliza redacción propia y recursos locales; no copia sus descripciones ni sus imágenes.

Las fichas usan los datos seleccionados de la wiki. Los perfiles y aprendizajes incluyen fuentes heredadas, las descripciones usan referencias y la compatibilidad de máquinas solo se muestra con el hash de destino coincidente. Estas páginas no acreditan efectos que no se hayan probado en partida.
