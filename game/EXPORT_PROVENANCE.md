# Export provenance

## English

This collaboration snapshot is a derived, path-sanitized copy of the project working tree. Text exports normalize local roots, and machine-readable hash references are rebased to the exported file bytes. The sibling `manifest.json` records source and export SHA-256 values, relative paths, transformations, exclusions, and the exporter hash. Markdown keeps its canonical source hashes.

The QA files in this snapshot are derivatives where listed in the manifest. They are not byte-identical frozen originals and do not replay or replace the original QA runs. Original working files were not modified. ROMs, saves, emulator states, archives, workflow files, caches, and pending Kris artwork are excluded.

## Español

Esta instantánea para colaboradores es una copia derivada y saneada del árbol de trabajo. El texto normaliza las raíces locales y las referencias de hashes legibles por máquina se actualizan al SHA-256 de los bytes exportados. El `manifest.json` contiguo registra hashes de origen y exportación, rutas relativas, transformaciones, exclusiones y el hash del exportador. Markdown conserva los hashes canónicos de origen.

Los archivos QA de esta instantánea son derivados cuando así lo indica el manifiesto. No son copias byte a byte de originales congelados ni reproducen o sustituyen las ejecuciones QA originales. Los archivos fuente no se modificaron. Se excluyen ROMs, partidas, estados de emulador, archivos comprimidos, workflows, cachés y el arte pendiente de Kris.
