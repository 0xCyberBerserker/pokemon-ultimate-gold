# Sacred Gold project guides

## English

This folder is the authored project documentation for the local Sacred Gold continuation. It covers the original National Dex 493 only. It is derived from the project reports, local audits and the historical manuals; it does not reproduce the upstream manuals or their prose.

Current patch output: `Sacred-Gold-Plus-Drayano-QoL-fix1.nds`, SHA-256 `fdb2fcabc4b51c4b98b0e4fcaf02740c81f32ede54c5a5bc0004d58c3133357e`. The preserved player build remains `3e405d796cae0ab7d6f67d89a8d9097220f58497a849a09ea0a56651910412c1`. Neither is presented as a stable all-game release.

Start with [the browser patcher guide](web-patcher.md). The generated website contains these guides and searchable derived tables.

Read in this order:

1. [Player guide](player-guide.md) — spoiler-light scope, play advice and known acceptance limits.
2. [Technical compatibility](technical-compatibility.md) — exact changes, compatibility and runtime gates.
3. [Data guide](data-guide.md) — 493 species, evolution and encounter provenance with accuracy tiers.
4. [Sources inventory](sources-inventory.md) — local inputs, hashes, missing spreadsheets and status.
5. [Discrepancy register](discrepancy-register.md) — inherited, modified, runtime-verified and pending claims.

Data: [493 species](species-493.csv), [15 changed moves](moves-final.csv), [all 2,086 trainer members](trainers-all-final.csv), [14 affected trainer members](trainers-final.csv). Trainer IDs and explicit move IDs come from the target ROM; automatic learnset moves are marked separately.

Cross-checks: [Drayano baseline](drayano-crosscheck.md), [all included components](mods-crosscheck.md), [pChal community resources](pchal-resources.md). Our tables take precedence over outside documents when describing this exact build.

Current status: [QA results](qa-493.md). Planned features: [evolution-item shops](evolution-items-qol.md), [complete cheat catalog](cheat-codes.md), [HM field actions without learned moves](hm-field-qol.md).

## Español

Esta carpeta contiene la documentación escrita para la continuación local de Sacred Gold. Cubre únicamente las 493 especies de la Pokédex Nacional original. Deriva de informes, auditorías locales y manuales históricos; no copia los manuales originales ni su prosa.

La versión de jugador preservada sigue siendo `3e405d796cae0ab7d6f67d89a8d9097220f58497a849a09ea0a56651910412c1`. Ninguna se presenta como release estable y aceptada de principio a fin.

Incluye [493 especies](species-493.csv), [15 movimientos modificados](moves-final.csv), [2.086 miembros de equipos](trainers-all-final.csv) y [14 miembros afectados](trainers-final.csv).
