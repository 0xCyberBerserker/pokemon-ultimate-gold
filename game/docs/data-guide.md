# Data guide / Guía de datos

## English

The current wiki payload, [`wiki-data.json`](wiki-data.json), is generated for Alpha 2 FIX6a, target SHA-256 `24ea9b16615d35b37b3a75f6c7d6fb1397d5ac851b88db8b78b7d3857a2725f6`. Its `inherited_data_sha256` value (`fdb2fc…`) identifies an earlier data lineage; it is not the target hash of this payload. The payload combines sources: move and item records are read from the selected ROM; species profiles and trainer teams reuse legacy exports. The Alpha 2 species base stats are cross-checked against [the exact-target comparison](species-stat-comparison.json). [The Alpha 2 build report](qa-alpha2-build.json) verifies that trainer header and party NARCs are byte-identical between Alpha 1 (`6e73ab…`) and Alpha 2 (`24ea9b…`) only. No checked artifact establishes that the `fdb2fc…` legacy trainer export matches Alpha 1, so that lineage remains unverified. Target message banks supply in-game names; matched references supply Spanish names and flavor text. The payload was last updated in this repository on 2026-10-31; that is a file-history date, not a gameplay test date.

The legacy hashes above are shown only where the paired JSON records them. CSV files without their own hash inherit that provenance only as paired exports; no hash is inferred for an unpaired file. Dates are the latest tracked changes in this checkout, not source-ROM dates or test dates. The current [`build_wiki_data.py`](../tools/build_wiki_data.py) validates its input against pinned target hashes and reads the relevant NARCs. The earlier `generate_species_table.py` and `generate_mod_tables.py` scripts are not present in this checkout.

Encounter information is historical and has different provenance: [`qa-493.md`](qa-493.md) records a fixture-assisted Route 29 capture and save check for legacy target `fdb2fc…`, dated 2026-10-21. [`discrepancy-register.md`](discrepancy-register.md) lists 142 map records but does not pin that count to an Alpha 2 hash. Neither source establishes Alpha 2's natural encounter distribution, complete species-to-location joins, map names or story availability. Original manual locations remain historical references.

Evolution entries are static methods, parameters and targets. Alternate-form learnsets and recovery after evolution through PC storage and a normal save still need testing. See [evolution items and shops](evolution-items-qol.md).

## Español

El payload actual de la wiki, [`wiki-data.json`](wiki-data.json), se genera para Alfa 2 FIX6a, con SHA-256 de destino `24ea9b16615d35b37b3a75f6c7d6fb1397d5ac851b88db8b78b7d3857a2725f6`. Su campo `inherited_data_sha256` (`fdb2fc…`) identifica una procedencia de datos anterior; no es el hash de destino de este payload. El payload combina fuentes: los registros de movimientos y objetos se leen de la ROM seleccionada; los perfiles de especies y equipos de entrenadores reutilizan exports legacy. Las estadísticas base de Alfa 2 se contrastan con [la comparación del target exacto](species-stat-comparison.json). [El informe de build de Alfa 2](qa-alpha2-build.json) verifica que los NARC de cabeceras y equipos son idénticos byte a byte solo entre Alfa 1 (`6e73ab…`) y Alfa 2 (`24ea9b…`). No se encontró un artefacto comprobado que demuestre que el export legacy de entrenadores `fdb2fc…` coincida con Alfa 1; esa relación sigue sin verificar. Los bancos de texto aportan los nombres del juego; las referencias emparejadas aportan los nombres en español y los textos descriptivos. El payload se actualizó por última vez en este repositorio el 2026-10-31; esa fecha corresponde al historial del archivo, no a una prueba de juego.

Los hashes legacy se muestran solo cuando constan en el JSON emparejado. Los CSV sin hash propio heredan esa procedencia únicamente como exports emparejados; no se infiere un hash para un archivo sin pareja. Las fechas son los últimos cambios registrados en este checkout, no las fechas de las ROM de origen ni de pruebas. El [`build_wiki_data.py`](../tools/build_wiki_data.py) actual valida la entrada contra hashes de destino fijados y lee los NARC pertinentes. Los antiguos scripts `generate_species_table.py` y `generate_mod_tables.py` no están en este checkout.

La información de encuentros es histórica y tiene otra procedencia: [`qa-493.md`](qa-493.md) registra una captura con fixtures y una comprobación de guardado en Ruta 29 para el target legacy `fdb2fc…`, con fecha 2026-10-21. [`discrepancy-register.md`](discrepancy-register.md) enumera 142 registros de mapas, pero no fija ese recuento a un hash de Alfa 2. Ninguna de las dos fuentes demuestra la distribución natural de Alfa 2, el cruce completo especie/ubicación, los nombres de mapas ni la disponibilidad durante la historia. Las ubicaciones de manuales originales siguen siendo referencias históricas.

Las evoluciones son métodos, parámetros y objetivos estáticos. Siguen pendientes los learnsets de formas alternativas y comprobar la recuperación tras evolucionar, pasar por el PC y guardar con normalidad. Véase [objetos evolutivos y tiendas](evolution-items-qol.md).
