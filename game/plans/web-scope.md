# Web delivery scope / Alcance de la entrega web

## English

The primary interface is a serverless browser patcher and our own searchable wiki, prepared for GitHub Pages. Existing NDS/GBA patchers hosted on Pages are implementation references; a proven local VCDIFF engine is preferred over a new decoder. The CLI and Qt interface remain optional local tools. The ROM is supplied by the user and processed locally; it must never be published or uploaded.

This scope was explicitly added on 2026-10-21. The bounded web implementation window ends at 18:48 UTC, with integration and verification reserved until 18:56 UTC. This does not renew the earlier gameplay QA window. No GitHub remote, push, or Pages publication is authorized.

Acceptance: the browser must reproduce the exact manifest target from the exact clean source, reject mismatched data, work below a project URL prefix, offer English and Spanish, and expose our derived documentation. A local end-to-end patch test is separate from full gameplay acceptance. Upstream documentation, pChal community sheets, and our actual ROM data retain distinct provenance.

## Español

La interfaz principal es un patcher de navegador serverless y nuestra wiki con búsqueda, preparados para GitHub Pages. Los patchers NDS/GBA existentes en Pages sirven de referencia; se prefiere un motor VCDIFF probado y local antes que crear otro decodificador. CLI y Qt quedan como herramientas locales opcionales. La ROM la aporta el usuario y se procesa localmente: nunca se publica ni se sube.

Este alcance se añadió expresamente el 21 de octubre de 2026. La implementación web tiene límite a las 18:48 UTC y reserva de integración y verificación hasta las 18:56 UTC. No renueva la ventana anterior de QA del juego. No hay autorización para remoto, push ni publicación en Pages.

Aceptación: reproducir el objetivo exacto del manifiesto desde la fuente exacta, rechazar datos incorrectos, funcionar bajo el prefijo de un proyecto, ofrecer English/Español y mostrar documentación propia derivada. La prueba local del parche es independiente de la aceptación completa del juego. Se conserva la procedencia diferenciada de documentación upstream, hojas comunitarias de pChal y datos reales de nuestra ROM.
